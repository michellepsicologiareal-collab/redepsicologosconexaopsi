SQL
Verificar status das psis premium
Confirma que a normalização funcionou e que existem psis premium aprovadas para aparecer no diretório.
SELECT nome, crp, status, premium
FROM psis
WHERE premium = true
ORDER BY nome;
-- Se retornar vazio: ainda não há psis premium.
-- Se retornar com status = 'Aprovado': o UPDATE de normalização não rodou.
2 Supabase — Edge Functions
Edge Function
Criar Edge Function: admin-proxy
Dashboard → Edge Functions → + New Function → nome: admin-proxy
Cole o conteúdo de admin-proxy_index.ts → Deploy.
URL resultante: https://tjtrdfbckgdgvcegdsbz.supabase.co/functions/v1/admin-proxy
Confirme que a URL bate com o PROXY_URL no admin.html.
Secrets
Adicionar secrets da Edge Function
Dashboard → Settings → Edge Functions → Add Secret. Adicione dois: 
ADMIN_MASTER_PASSWORD  =  MasterPsi2026!
ADMIN_SOCIO_PASSWORD   =  SocioPsi2026!
# SUPABASE_URL e SUPABASE_SERVICE_ROLE_KEY são injetadas automaticamente
Teste
Testar admin-proxy (opcional mas recomendado)
Cole no terminal ou use o Supabase Logs para verificar:
curl -X POST \
  https://tjtrdfbckgdgvcegdsbz.supabase.co/functions/v1/admin-proxy \
  -H "Content-Type: application/json" \
  -H "apikey: SUA_ANON_KEY" \
  -d '{"action":"update","table":"psis","id":"ID_INEXISTENTE","payload":{"bio":"teste"},"adminPassword":"MasterPsi2026!"}'
# Esperado: {"ok":true,"data":[]} (array vazio pois ID não existe)
# Se retornar {"error":"Não autorizado"}: secret não foi salvo corretamente

4 Validação final
Teste
Testar admin.html — aprovar, premium, editar com foto
1. Login → Pendentes: deve aparecer card com badge 🧠 ou 🏥
2. Aprovar uma psi → conferir que muda para Aprovados
3. Ativar Premium → conferir aba Premium
4. Editar → selecionar foto → salvar → foto deve aparecer no card
Teste
Testar met.html — Profissionais da rede
1. Login com e-mail de uma psi premium aprovada
2. Aba "Profissionais da rede" → deve listar as psis premium
3. Se vazio: clicar F12 → Console → copiar o erro e verificar
Se aparecer "X aprovados sem premium": acesse admin.html → encontre a psi → clique ✨ Premium → volte ao met.html e atualize.
Teste
Testar divulgacao.html — filtros Online/Presencial/Ambos
Clicar em "Online" deve mostrar psis com formato Online E psis com formato Ambos.
Antes só mostrava Online exato.
Diagnóstico Admin
Rodar Diagnóstico no admin.html (aba 🩺)
Após tudo deployado: Admin → aba Diagnóstico → "Rodar diagnóstico".
Todas as 3 tabelas devem aparecer com ✓ existe.
Simular login com e-mail de psi premium → deve mostrar "LIBERADO".
