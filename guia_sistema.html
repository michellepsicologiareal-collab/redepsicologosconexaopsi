Financeiro
Como funciona o controle de pagamentos, planos e mensalidades no painel admin.
Três planos disponíveis
🎁 PsiMed Grátis
Para médicos, psiquiatras e parceiros que não pagam mensalidade. Aparecem como "Grátis" no Financeiro. O botão de confirmar pagamento não aparece.
⭐ PsiMed Fundadora
Para psicólogas que entraram com o cupom FUNDADORA ou negociaram desconto. Valor padrão: R$ 19,90/mês. Editável em ⚙️ Planos.
💜 PsiMed Premium
Plano padrão para novas assinantes. Valor padrão: R$ 27,90/mês. O MRR é calculado com base no plano real de cada pessoa.
Como confirmar pagamento do mês
1. Acesse a aba Financeiro no admin—
2. Cada pessoa tem um botão "⏳ Confirmar"aparece para planos pagos
3. Após receber o Pix/transferência, clique no botãovira ✅ Pago
4. O card fica com borda verde e o KPI "Pagos este mês" atualizaautomático
5. Todo mês 1 a confirmação resetasalvo por mês/ano no navegador
💡 As confirmações de pagamento ficam salvas localmente no seu navegador (localStorage). Se trocar de computador, precisará reconfirmar. Futuramente isso pode ser migrado para uma coluna no banco.
Como editar os planos
1. Clique no botão ⚙️ Planos no Financeirocanto superior direito
2. Edite nome, valor (R$) e descrição de cada planocampos editáveis
3. Adicione novos planos ou remova os que não usa+ Adicionar plano
4. Clique em 💾 Salvar e fecharsalvo no navegador
5. O MRR e ARR recalculam na horaautomático
Mensagem WhatsApp por plano
📲 Como funciona o botão WA
Cada pessoa na lista tem um botão "📲 WA" que abre o WhatsApp com uma mensagem já preenchida, personalizada com o nome da pessoa, o plano dela e o valor do mês. Para planos grátis, a mensagem é de agradecimento sem mencionar cobrança.

Exemplo para plano Premium:
"Olá, Ana! 💜 Aqui é a Michelle da Conexão Psi. Passando para avisar que a mensalidade do plano PsiMed Premium referente a abril no valor de R$ 27,90 está disponível..."

Manutenção
SQLs de rotina, diagnóstico por sintoma e procedimento de troca de senha.
SQLs de rotina
📊 Resumo por status
SELECT status, COUNT(*) FROM psis GROUP BY status ORDER BY status;
✨ Psis premium aprovadas
SELECT nome, crp, email, cidade FROM psis
WHERE premium = true AND status = 'aprovado' ORDER BY nome;
🔡 Normalizar status (maiúscula → minúscula)
UPDATE psis SET status = LOWER(status) WHERE status != LOWER(status);
UPDATE profissionais_saude SET status = LOWER(status) WHERE status != LOWER(status);
⚠️ Psis sem e-mail
SELECT nome, crp, handle FROM psis WHERE email IS NULL OR email = '';
