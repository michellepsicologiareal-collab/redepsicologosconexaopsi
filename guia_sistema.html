Páginas do Sistema
Cada arquivo HTML é independente — sem framework, sem build. CSS e JS inline. Deploy automático via GitHub Pages.
📄 index.html — Área interna
Membros aprovados
Todas as psis aprovadas (gratuitas + premium). Filtros por abordagem, formato, cidade. Botão "Atualizar perfil" com verificação por e-mail. Upload de foto via clever-handler. Stats da rede no hero.
🌐 divulgacao.html — Diretório público
Pacientes
Apenas psis com premium=true e status=aprovado. Filtros Online/Presencial incluem formato "Ambos". Botão WhatsApp direto. CTA de cadastro para novas psicólogas.
🤝 met.html — PsiMed Rede
Premium + Aprovado
Login por e-mail (lookup ilike nas duas tabelas). 3 abas: Indicações · Indicar · Profissionais. Aba Diagnóstico visível só para admin. Registrar interesse notifica admin via WA.
👑 admin.html — Painel
Senha admin
Tabs unificadas Pendentes/Aprovados/Premium (psis + meds). Badge 🧠/🏥 em cada card. Upload de foto nos modais. Escritas via Edge Function admin-proxy. Aba 🩺 Diagnóstico (Master).

Manutenção
SQLs de rotina, diagnóstico por sintoma e procedimento de troca de senha.
SQLs de rotina
📊 Resumo por status
SELECT status, COUNT(*) FROM psis GROUP BY status ORDER BY status;
✨ Psis premium aprovadas
SELECT nome, crp, email, cidade FROM psis
WHERE premium = true AND status = 'aprovado' ORDER BY nome;
🔡 Normalizar status (maiúscula → minúscula)
UPDATE psis SET status = LOWER(status) WHERE status != LOWER(status);
UPDATE profissionais_saude SET status = LOWER(status) WHERE status != LOWER(status);
⚠️ Psis sem e-mail (não conseguem logar)
SELECT nome, crp, handle FROM psis WHERE email IS NULL OR email = '';
