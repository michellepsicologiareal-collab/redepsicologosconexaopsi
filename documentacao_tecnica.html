Páginas do Sistema
Cada arquivo HTML é independente — sem framework, sem build. Lógica JS inline, estilo CSS inline.
📄 index.html — Área interna
Membros aprovados
Diretório completo de todas as psis aprovadas (gratuitas + premium). Filtros por abordagem, formato, cidade. Botão "Atualizar perfil" com verificação por e-mail. Upload de foto via clever-handler. Stats de rede no hero.
🌐 divulgacao.html — Diretório público
Pacientes
Mostra apenas psis com premium=true e status=aprovado. Filtros Online/Presencial incluem formato "Ambos". Tags de abordagem. Botão WhatsApp direto. CTA de cadastro para psicólogas.
🤝 met.html — PsiMed Rede
Premium + Aprovado
Login por e-mail (lookup nas duas tabelas). 3 abas: Indicações recebidas · Indicar paciente · Profissionais da rede. Registrar interesse notifica admin via WhatsApp.
👑 admin.html — Painel admin
Senha admin
Tabs: Pendentes · Aprovados · Premium · Prof. Saúde · Encaminhamentos · Todos · Sistema · Diagnóstico. Cards unificados com badge 🧠/🏥. Upload de foto nos modais. Escritas via Edge Function.

Edge Function — admin-proxy

Risco residual: qualquer pessoa pode fazer INSERT em psis com a anon key. Isso é intencional (Tally precisa). O impacto é baixo pois todos os cadastros chegam como status=pendente e precisam de aprovação manual.
Proteção ativa: UPDATE e DELETE em psis e profissionais_saude só funcionam via service_role, que nunca sai do servidor Supabase.
Manutenção
Operações rotineiras, SQLs úteis e procedimentos de recuperação.
SQLs de rotina
📊 Resumo por status
SELECT status, COUNT(*) FROM psis GROUP BY status ORDER BY status;
✨ Psis premium aprovadas
SELECT nome, crp, email, cidade FROM psis
WHERE premium = true AND status = 'aprovado'
ORDER BY nome;
⚠️ Psis sem e-mail (não conseguem logar no met.html)
SELECT nome, crp, handle FROM psis
WHERE email IS NULL OR email = '';
🔄 Normalizar status (maiúscula → minúscula)
UPDATE psis SET status = LOWER(status)
WHERE status != LOWER(status);

UPDATE profissionais_saude SET status = LOWER(status)
WHERE status != LOWER(status);
🧹 Limpar encaminhamentos concluídos (>30 dias)
DELETE FROM encaminhamentos_cruzados
WHERE status = 'concluido'
  AND created_at < NOW() - INTERVAL '30 days';
