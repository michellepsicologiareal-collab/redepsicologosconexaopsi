SQL para criar a tabela meet_requests:
CREATE TABLE meet_requests (id uuid DEFAULT gen_random_uuid() PRIMARY KEY, solicitante_nome text, solicitante_registro text, solicitante_wa text, destinatario_nome text, destinatario_registro text, tipo text, mensagem text, disponibilidade text, status text DEFAULT 'pendente', created_at timestamptz DEFAULT now()); ALTER TABLE meet_requests ENABLE ROW LEVEL SECURITY; CREATE POLICY "sel_meet" ON meet_requests FOR SELECT USING (true); CREATE POLICY "ins_meet" ON meet_requests FOR INSERT WITH CHECK (true); CREATE POLICY "upd_meet" ON meet_requests FOR UPDATE USING (true);

Manutenção
SQLs de rotina, diagnóstico por sintoma e procedimentos operacionais.
SQLs de rotina
📊 Resumo por status
SELECT status, COUNT(*) FROM psis GROUP BY status ORDER BY status;
🔡 Normalizar status (se vier com maiúscula do Tally)
UPDATE psis SET status = LOWER(status) WHERE status != LOWER(status);
UPDATE profissionais_saude SET status = LOWER(status) WHERE status != LOWER(status);
⚠️ Psis sem e-mail (não conseguem logar)
SELECT nome, crp, handle FROM psis WHERE email IS NULL OR email = '';
🤝 Meets pendentes
SELECT solicitante_nome, destinatario_nome, tipo, created_at
FROM meet_requests WHERE status = 'pendente' ORDER BY created_at DESC;
