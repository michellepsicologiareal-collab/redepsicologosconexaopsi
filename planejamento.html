Pontos críticos de atenção
⚠ Gargalo 1 — Ativação manual

A ativação premium depende de operação manual no admin. Com volume isso vira gargalo. Solução: webhook Kiwify → Edge Function que ativa premium=true automaticamente após pagamento confirmado.

⚠ Gargalo 2 — Aprovação de cadastros

Aprovação manual de cada CRP. Com 100+ cadastros fica insustentável. Solução: aprovação em lote no admin + critérios documentados para poder delegar.

💡 Gatilho de conversão F2 → F3

O psi gratuito precisa sentir que está perdendo algo. Sugestão: "3 pacientes indicados para você este mês — desbloqueie premium para aceitar" via WhatsApp ou e-mail.

💡 Retenção premium

Se não receber nenhum contato no 1º mês, cancela. Implemente relatório mensal: "seu perfil foi visto 14x" ancora valor percebido mesmo sem contato direto.

💰 Por que a margem é excepcionalmente alta

Com custo fixo próximo a zero, cada novo assinante representa quase receita líquida. 100 psis = R$2.790/mês com margem bruta de ~94% (descontando taxa Kiwify). A ameaça não é o custo — é o churn e a velocidade de aquisição.

Tier atual — R$27,90/mês

Valor baixo facilita conversão. Ideal para aquisição. Risco: âncora difícil de quebrar depois. Não suba o preço de quem já assinou, mas novos tiers podem ter preço maior.

⚠ Alerta Regulatório — CFP Resolução 06/2019

A resolução proíbe captação de clientela e anúncios que pareçam comercialização da relação terapêutica. Um diretório pago pode ser enquadrado como prática vedada dependendo do posicionamento. O ponto defensável: a plataforma é de indicação entre profissionais, não de publicidade ao público geral. Documentar nos termos de uso antes de escalar.

Mapa de riscos
Alto
Dependência de operação manual
Toda aprovação, ativação premium e moderação passa por você. Com 200+ cadastros torna-se inviável e gera atrasos que deterioram a experiência.
→ Prioridade imediata: automatizar webhook Kiwify + aprovação em lote. Meta: 0 etapas manuais para ativação premium.
Alto
Churn por falta de resultado percebido
Se o psi premium não receber pacientes no 1º mês, cancela. O valor prometido depende de volume de tráfego para o diretório, ainda baixo.
→ Construir prova social ativa: depoimentos, número de visualizações de perfil, indicações recebidas. Gerenciar expectativas no onboarding.
Alto
Regulação CFP sobre captação digital
Posicionamento atual vulnerável se concorrente ou colega acionar o CFP. "Plataforma de indicação entre profissionais" é defensável mas precisa ser explícito.
→ Consultar advogado com expertise em saúde digital. Redigir termos de uso com linguagem alinhada ao CFP antes de escalar.
Médio
Lançar PsiMed antes de ter massa crítica
Médicos que entram e encontram poucos psis premium disponíveis simplesmente saem. Custo de reativação é alto.
→ Threshold mínimo: lançar PsiMed com 50+ psis premium e distribuição em ao menos SP + RJ.
Médio
Plataforma sem backup nem redundância
Supabase Free Plan sem backups agendados. Drop acidental pode causar perda irreversível de dados (já ocorreu).
→ Com a primeira receita, migrar para Supabase Pro (~USD 25/mês). Exportação mensal via SQL como seguro adicional.
Médio
Marca "Conexão Psi" sem registro
Concorrente pode registrar antes e forçar rebranding custoso.
→ Protocolar registro no INPI (classe 44). Custo: ~R$355. A data de protocolo garante prioridade mesmo enquanto tramita.
Baixo
Cópia por concorrente maior (Wepsy, etc.)
Concorrentes B2C não replicam o diferencial psi-a-psi porque seu modelo é outro. O moat real é a rede de confiança, não a tecnologia.
→ Acelerar crescimento da rede — em redes profissionais, tamanho é defesa.

Construir a base — sem acelerar prematuramente
Foco exclusivo em qualidade da rede e conversão para premium. Não lançar PsiMed publicamente ainda.

  • Automatizar ativação premium via webhook Kiwify → Edge Function
  • Criar fluxo de onboarding pós-aprovação (e-mail boas-vindas + tutorial)

  • Registrar marca "Conexão Psi" no INPI (classe 44) — ~R$355

Fase 2 · Meses 4–8 · Expansão controlada
Lançar PsiMed + Expandir geograficamente
Com 50+ psis premium, a rede tem valor mínimo para médicos. Iniciar aquisição ativa de médicos (psiquiatras primeiro).
  • Meta: 100 psis premium + 30 médicos ativos no PsiMed
  • Plano anual (2 meses grátis) para reduzir churn
  • SEO por cidade/especialidade em divulgacao.html
  • Tier Pro (R$49,90 com destaque + relatórios)
  • Parcerias estratégicas: CRP regional, faculdades de psicologia
  • SLA de aprovação: máx 48h após cadastro
Fase 3 · Meses 9–18 · Escalabilidade real
Monetizar PsiMed + Automação total
Sistema operando sem intervenção manual. Receita suficiente para contratar suporte ou dev part-time.
  • Meta: 300+ psis premium · R$8.000+/mês
  • Cobrar médicos por acesso premium ao PsiMed
  • Destaque pago no diretório por cidade/abordagem
  • PWA mobile — diferencial perceptual enorme
  • Estruturar equipe: 1 CS + 1 dev part-time
  • Avaliar aceleração (SEBRAE, investidor anjo)
