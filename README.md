# Rede Psicólogos Conexão Psi

Este repositório contém o site da **Rede de Psicólogos Conexão Psi**, um espaço colaborativo para referências profissionais e informações sobre psicologia.

## 🌐 Site publicado
Acesse o site em:  
[https://michellepsicologiareal-collab.github.io/redepsicologosconexaopsi/](https://michellepsicologiareal-collab.github.io/redepsicologosconexaopsi/)

## 📌 Objetivo
- Criar uma rede de apoio entre psicólogos.  
- Compartilhar informações e contatos profissionais.  
- Facilitar o acesso a referências confiáveis na área da psicologia.

## 🚀 Como atualizar
1. Edite os arquivos HTML ou CSS neste repositório.  
2. Salve as alterações com **Commit changes**.  
3. O GitHub Pages atualiza automaticamente o site em alguns minutos.
