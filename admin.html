🗺️ Visão Geral do Sistema

A Conexão Psi é uma plataforma web colaborativa para gerenciar uma rede de psicólogos. Permite cadastro, aprovação, gestão de perfis, encaminhamento de pacientes e captação pública via diretório premium.

Objetivos
  • Diretório colaborativo com perfis gratuitos e premium
  • Encaminhamento de pacientes entre membros da rede
  • Visibilidade pública para captação orgânica de clientes
  • Monetização via assinatura Premium (R$27,90/mês, 1ª cobrança R$20)
  • Rastreamento de origem de visitantes via UTM

Comunicação com o Backend

Toda comunicação usa a API REST do Supabase diretamente no navegador via fetch(). Não há servidor intermediário.

const SB = 'https://tjtrdfbckgdgvcegdsbz.supabase.co'; const KEY = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...'; const H = { 'apikey': KEY, 'Authorization': 'Bearer ' + KEY }; async function api(method, path, body) { const r = await fetch(SB + '/rest/v1/' + path, { method, headers: H, body: body ? JSON.stringify(body) : undefined }); return r.json(); }
⚠️ A chave anon KEY está exposta no HTML (lado cliente). Qualquer pessoa pode inspecioná-la. O RLS do Supabase é a principal camada de proteção — mantenha-o corretamente configurado.

🗄️ Demais Tabelas
profissionais_saude

Médicos e outros profissionais para o módulo PsiMed (met.html). Colunas: id, nome, especialidade, crm_crp_etc, email, status, created_at.

encaminhamentos_cruzados

Indicações entre psicólogos e outros profissionais no PsiMed. Colunas: id, tipo_profissional, urgencia, demanda, status, quem_indicou, whatsapp_paciente, created_at.

visitas_divulgacao

Rastreamento UTM de visitantes da página pública. Criada pelo arquivo visitas_divulgacao.sql.

-- Origens dos últimos 30 dias SELECT source, COUNT(*) as visitas FROM visitas_divulgacao WHERE created_at > NOW() - INTERVAL '30 days' GROUP BY source ORDER BY visitas DESC;
💡 Para criar a tabela visitas_divulgacao: Supabase → SQL Editor → cole o conteúdo do arquivo visitas_divulgacao.sql → Run.
📄 index.html — Diretório Interno

Página principal da rede. Exibe o diretório de psicólogos com busca, filtros e edição de perfil inline.

  • Estatísticas dinâmicas (total de profissionais e premium)
  • Busca por nome, especialidade, cidade
  • Filtros por abordagem, formato e estado
  • Cards diferenciados para membros premium
  • Modal de edição de perfil inline por email
  • Seção de convite com mensagem copiável para WhatsApp
📄 divulgacao.html — Página Pública

Vitrine pública para pacientes encontrarem psicólogos. Exibe apenas profissionais com status = aprovado e premium = true.

  • Busca e filtros por abordagem e formato
  • Cards com bio, especialidades, valor e botão WhatsApp
  • Rastreamento automático de visitas por UTM
  • CTA para novos psicólogos se cadastrarem

🔄 Cadastro de Nova Psicóloga
1
Psicóloga preenche formulário em tally.so/r/b5OGYZ
2
Tally envia dados para tabela psis com status = pendente
3
Admin acessa admin.html → aba Pendentes, verifica CRP no site do CFP
4
Admin clica Aprovar → status = aprovado
5
Psicóloga é notificada pelo WhatsApp e acessa perfil.html para completar perfil
🔄 Ativação de Perfil Premium
1
Psicóloga acessa planos.html → clica "Assinar Premium"
2
WhatsApp da administração abre com mensagem pré-formatada
3
Admin recebe pagamento (PIX ou método combinado)
4
Admin acessa admin.html → localiza a psi → clica Ativar Premium → premium = true
5
Perfil passa a aparecer em destaque em divulgacao.html
🔄 Encaminhamento de Paciente
1
Paciente é cadastrado no sistema com status = disponivel
2
Aparece na aba Disponíveis do pacientes.html
3
Psicóloga clica "Tenho interesse" — nome entra no array interessados (máx 3)
4
Admin libera para atendimento → status = em_atendimento
5
Psicóloga responsável contata paciente pelo WhatsApp
6
Ao finalizar → clica "Concluir" → status = concluido
🛡️ Vulnerabilidades & Recomendações
ItemRiscoRecomendação
Senhas hardcoded no HTMLAltoMigrar para Supabase Auth com tokens JWT
Chave anon expostaMédioManter RLS corretamente configurado em todas as tabelas
RLS desabilitado em visitas_divulgacaoBaixoAceitável — tabela só registra visitas públicas
Sem validação server-sideMédioAdicionar validações via Supabase Edge Functions
Sem rate limitingMédioConfigurar rate limiting no Supabase ou no Tally
Pagamento manual (WhatsApp)Alto (operacional)Integrar gateway real (Stripe, Mercado Pago) futuramente
Boas Práticas Implementadas
  • Uso da chave anon (não a service_role) no frontend
  • Dados de pacientes com identificação mínima (sem prontuário clínico)
  • Verificação de CRP manual antes da aprovação
  • Campos premium e status só alteráveis pelo admin
