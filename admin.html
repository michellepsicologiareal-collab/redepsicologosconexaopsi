Banco de dados
SQL Úteis
Queries prontas para rodar no Supabase SQL Editor. Clique em "Copiar" e cole diretamente.
1. Encontrar duplicatas por nome Manutenção
Mostra psis com nomes repetidos para limpeza manual.
SELECT nome, COUNT(*) AS total FROM psis GROUP BY nome HAVING COUNT(*) > 1 ORDER BY total DESC;
2. Duplicatas por CRP Manutenção
Identifica CRPs cadastrados mais de uma vez.
SELECT crp, COUNT(*) AS total, STRING_AGG(nome, ', ') AS nomes FROM psis WHERE crp IS NOT NULL GROUP BY crp HAVING COUNT(*) > 1;
3. Listar psis Premium Consulta
Todas as psis com status premium ativo, ordenadas por nome.
SELECT nome, crp, email, cidade, created_at FROM psis WHERE status = 'premium' ORDER BY nome ASC;
4. Psis com dados incompletos Manutenção
Encontra perfis sem cidade, abordagem, formato ou CRP.
SELECT nome, email, crp, cidade, abordagem, formato FROM psis WHERE cidade IS NULL OR cidade = '' OR abordagem IS NULL OR abordagem = '' OR formato IS NULL OR formato = '' OR crp IS NULL OR crp = '' ORDER BY nome;
5. Fotos com URL corrompida Manutenção
Encontra foto_url que não começa com https:// — pode estar quebrada no site.
SELECT nome, crp, foto_url FROM psis WHERE foto_url IS NOT NULL AND foto_url != '' AND foto_url NOT LIKE 'https://%' ORDER BY nome;
6. Verificar RLS (Row Level Security) Segurança
Confirma se RLS está ativado na tabela psis e lista as policies existentes.
-- Verificar se RLS está ON SELECT tablename, rowsecurity FROM pg_tables WHERE tablename = 'psis'; -- Listar policies SELECT policyname, cmd, qual FROM pg_policies WHERE tablename = 'psis';
7. Contagem por status Consulta
Resumo rápido: quantas psis em cada status (pendente, ativo, premium, etc).
SELECT status, COUNT(*) AS total FROM psis GROUP BY status ORDER BY total DESC;
8. Premium por CRP (busca rápida) Consulta
Busca uma psi específica pelo CRP para verificar se é premium.
-- Troque 'XX/XXXXX' pelo CRP desejado SELECT nome, crp, status, email, cidade FROM psis WHERE crp ILIKE '%XX/XXXXX%';
